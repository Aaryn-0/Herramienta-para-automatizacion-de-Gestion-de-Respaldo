Laboratorio de Pruebas y Evidencias de Evaluación

Entorno para demostrar los 6 escenarios requeridos en la especificación académica (Sección 4 y 14 del PDF).

Prueba Requerida 1

Ejecución Exitosa con Validación

Ejecuta un respaldo completo/incremental, valida bloques físicos con RESTORE DATABASE VALIDATE y genera archivos en disco.

Prueba Requerida 2

Simulación Controlada: Error NOARCHIVELOG

Simula intento de backup online con base abierta en NOARCHIVELOG (RMAN-06149: cannot BACKUP DATABASE in NOARCHIVELOG mode) para evidenciar detección preventiva.

Prueba Requerida 3

Simulación Controlada: Disco Lleno

Simula aborto de respaldo por falta de espacio en destino (ORA-19504: failed to create file / OSD-04008), disparando alerta de Disponibilidad.

Prueba Requerida 4

Ejecución con Advertencias

Simula respaldo que concluye pero con advertencias del catálogo RMAN (RMAN-06497: WARNING: redundant backup ignored).

Prueba Requerida 5

Escenario 2 No Archive: Cold Backup Consistente

Ejecuta el flujo correcto para NOARCHIVELOG: Shutdown Immediate -> Startup Mount -> Backup Database -> Open Database.

Prueba Requerida 6

Transformación 24/7: Migración ARCHIVELOG

Consulte el procedimiento oficial DBA para habilitar modo ARCHIVELOG en la base local XE y permitir respaldos en caliente 24/7.
